# Tab Vault

A Chrome extension that saves all your open windows and tabs with one click and restores them after a reboot.

- Each save is labelled with the date and time.
- You can view each save window by window, restore everything, or restore a single window.
- Pinned tabs, tab groups and window sizes are restored.
- An optional auto-save runs every 30 minutes.
- Everything stays on your computer.
